# Заявки с сайта → Telegram: настройка

Как это работает:

```
Сайт (форма)  →  Cloudflare Worker  →  Telegram Bot API  →  группа «Barber Studio — Записи»
                 (хранит токен бота
                  в секрете)
```

Всё бесплатно. Понадобится около 15 минут, Telegram и браузер.
Устанавливать на компьютер ничего не нужно.

---

## Шаг 1. Бот

Нужен **токен бота** — строка вида `1234567890:AAH...`.

- **Если у тебя уже есть бот** `@barbershop_barbershop_bot_bot` и его токен — используй его.
  Для уведомлений бот только отправляет сообщения, поэтому это не мешает тому, что он уже умеет.
- **Если бота нет или токена нет** — создай отдельного бота для уведомлений:
  1. Открой в Telegram [@BotFather](https://t.me/BotFather) → `/newbot`
  2. Придумай имя (например, `Barber Studio Заявки`) и username, который заканчивается на `bot`
  3. BotFather пришлёт токен — сохрани его, **никому не показывай и не вставляй в код сайта**

> Токен — это пароль от бота. Если он случайно попал в GitHub или в чат,
> зайди в @BotFather → `/revoke`, выбери бота и получи новый токен.

## Шаг 2. Группа для администраторов

1. Создай в Telegram группу, например `Barber Studio — Записи`
2. Добавь в неё администраторов барбершопа и **своего бота**
3. Напиши в группе команду с именем бота, например: `/start@имя_твоего_бота`

## Шаг 3. Узнать ID группы (CHAT_ID)

1. Открой в браузере ссылку, подставив свой токен:
   ```
   https://api.telegram.org/bot<ТОКЕН>/getUpdates
   ```
2. Найди в ответе кусок вида `"chat":{"id":-1001234567890,"title":"Barber Studio — Записи"`
3. Число вместе с минусом (`-1001234567890`) — это **CHAT_ID**

Если в ответе пусто (`"result":[]`), напиши в группе ещё раз `/start@имя_бота` и обнови страницу.

Если видишь ошибку `Conflict: can't use getUpdates method while webhook is active`,
значит бот уже подключён к другому серверу. Проще всего создать отдельного бота
для уведомлений (Шаг 1, второй вариант).

## Шаг 4. Cloudflare Worker

1. Зарегистрируйся на [dash.cloudflare.com](https://dash.cloudflare.com/sign-up) (бесплатно, карта не нужна)
2. В меню слева: **Workers & Pages** → **Create** → **Create Worker**
3. Назови его, например, `barber-booking` → **Deploy**
4. Нажми **Edit code**, удали весь пример и вставь целиком код из файла `telegram-worker/worker.js` → **Deploy**
5. Вернись к Worker'у → **Settings** → **Variables and Secrets** → **Add**:
   | Type | Name | Value |
   | --- | --- | --- |
   | Secret | `BOT_TOKEN` | токен из Шага 1 |
   | Secret | `CHAT_ID` | число из Шага 3, с минусом |

   Нажми **Deploy** / **Save**
6. Скопируй адрес Worker'а. Он вида `https://barber-booking.твой-ник.workers.dev`

> Названия кнопок в Cloudflare иногда меняются, но разделы Workers & Pages
> и Settings → Variables всегда есть.

## Шаг 5. Подключить сайт

1. В файле `script.js` вставь адрес Worker'а:
   ```js
   const BOOKING_ENDPOINT = "https://barber-booking.твой-ник.workers.dev";
   ```
2. Если сайт живёт не на `https://blessedrbls.github.io`, добавь свой домен
   в список `ALLOWED_ORIGINS` в начале `worker.js` (в Cloudflare) и снова нажми **Deploy**.
   С других сайтов Worker заявки не принимает.

## Шаг 6. Проверка

1. Запусти сайт локально:
   ```bash
   cd ~/Desktop/barbershop-site && python3 -m http.server 8080
   ```
2. Открой http://localhost:8080, заполни форму и отправь
3. Через секунду в группе появится сообщение:
   ```
   🆕 Нова заявка з сайту

   📅 Пт, 13.11.2026 о 19:00
   📍 вул. Гончара, 15
   ✂️ Стрижка + борода — 750 грн, 90 хв
   💈 Дмитро Шевченко

   👤 Максим
   📞 +380 67 123 45 67

   Заявку надіслано 10.11.26, 18:30 · мова сайту: UA
   ```

> **Изменили `worker.js`?** Cloudflare сам не узнает о правках в файле на компьютере.
> Открой Worker → **Edit code**, замени весь код новым содержимым `worker.js` → **Deploy**.
> Секреты при этом сохраняются.

> Если открыть `index.html` двойным кликом (адрес начинается с `file://`), отправка не сработает:
> Worker принимает заявки только с адресов из списка `ALLOWED_ORIGINS`. Проверяй через `localhost:8080`.

# Часть 2. Занятое время и кнопки «Підтвердити / Скасувати»

После этой части:
- после выбора мастера сайт показывает **только его свободные часы** — занятые скрыты;
- два человека не смогут записаться к одному мастеру на одно время, даже если нажмут кнопку одновременно;
- под каждой заявкой в Telegram появятся кнопки **✅ Підтвердити** и **❌ Скасувати**.
  «Скасувати» освобождает время на сайте.

Заявки хранятся в бесплатной базе данных Cloudflare **D1**. Таблицы Worker создаёт сам,
писать SQL не нужно.

## Шаг 7. Создать базу D1

1. Cloudflare → меню слева **Storage & databases** → **D1 SQL database**
2. **Create** (или **Create database**) → имя `barber-bookings` → **Create**

## Шаг 8. Подключить базу к Worker'у

1. **Workers & Pages** → `barber-booking` → **Settings** → раздел **Bindings** → **+ Add binding**
2. Выбери **D1 database**
3. **Variable name:** `DB` (именно так, большими буквами)
4. **D1 database:** `barber-bookings`
5. **Add binding** / **Deploy**

## Шаг 9. Придумать пароль для кнопок (WEBHOOK_SECRET)

По этому паролю Worker понимает, что нажатие кнопки пришло именно от Telegram, а не от постороннего.

1. Придумай строку **от 16 символов** из латинских букв, цифр и `_`.
   Например: `barber_knopky_7f3k9q2m` (только придумай свою)
2. Worker → **Settings** → **Variables and Secrets** → **+ Add**:
   - Type: **Secret**, Name: `WEBHOOK_SECRET`, Value: твоя строка
3. **Deploy**

## Шаг 10. Обновить код Worker'а

**Edit code** → удали всё → вставь новое содержимое `telegram-worker/worker.js` → **Deploy**.

## Шаг 11. Включить кнопки

Открой в браузере (подставь свою строку из Шага 9):
```
https://barber-booking.твой-ник.workers.dev/setup-webhook?key=ТВОЙ_WEBHOOK_SECRET
```
Должно появиться: **«✅ Готово! Кнопки «Підтвердити / Скасувати» підключено.»**
Это делается один раз.

> После этого бот получает только нажатия кнопок. `getUpdates` из Шага 3 для него
> больше работать не будет — это нормально.

## Шаг 12. Проверка

1. Отправь заявку с сайта → в группе появится сообщение с кнопками
2. Обнови сайт, выбери того же мастера и день → этого часа в списке **больше нет**
3. Нажми в Telegram **❌ Скасувати** → сообщение изменится на «Скасовано»,
   а на сайте (после обновления страницы) этот час снова свободен

## Как считается занятость

- **По мастеру.** Если Дмитро занят в 19:00, к Олександру на 19:00 записаться можно.
  Мастер не может быть в двух филиалах сразу, поэтому филиал на занятость не влияет.
- **«Будь-який майстер»** → Worker сам назначает свободного мастера (у кого меньше записей в этот день).
  В сообщении будет пометка «призначено автоматично».
- **Длинные услуги** занимают несколько часов: «Стрижка + борода» (90 хв) в 19:00 занимает 19:00 и 20:00.
- **Отмена** — только кнопкой «❌ Скасувати» в Telegram. Если клиент перенёс запись по телефону,
  отмени старую заявку кнопкой, и время освободится.

## Если не работает

| Что видишь | Что делать |
| --- | --- |
| На сайте: «Не вдалося надіслати заявку» | Открой в Cloudflare свой Worker → **Logs** (или **Observability**), отправь форму ещё раз и посмотри ошибку |
| В логах `BOT_TOKEN або CHAT_ID не задані` | Проверь Шаг 4.5: имена переменных должны быть точно `BOT_TOKEN` и `CHAT_ID` |
| В логах `chat not found` | Неправильный CHAT_ID или бота нет в группе |
| В логах `Unauthorized` | Неправильный токен |
| В логах `group chat was upgraded to a supergroup` | У группы сменился ID. Повтори Шаг 3 и обнови `CHAT_ID` |
| В консоли браузера ошибка CORS | Адрес сайта не добавлен в `ALLOWED_ORIGINS` |
| Занятые часы не зачёркиваются | Проверь Шаг 8: binding называется точно `DB`. Открой `https://…workers.dev/availability` — там должно быть `"enabled":true` |
| `/setup-webhook` пишет «Невірний key» | Значение `key=` в ссылке должно совпадать с `WEBHOOK_SECRET` один в один |
| Кнопки в Telegram крутятся и ничего не происходит | Повтори Шаг 11. Если не помогло — смотри логи Worker'а |
